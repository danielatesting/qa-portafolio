# Restaurant ERP

## Overview

This project documents my experience performing manual exploratory testing on a web-based Restaurant ERP.
The goal is to document my testing approach, test documentation, and learning process while working on a real software project.

The application includes modules for:

- Dashboard
- Guest Services
- Purchases
- Marketing
- Staff
- System

My responsibilities include:

- Exploratory testing
- Functional testing
- Reporting defects in ClickUp
- Verifying fixes

> This documentation focuses on the QA process and does not include confidential business information.
