# Test Plan

## Purpose

This document defines the testing scope, objectives, approach, and priorities for the Restaurant ERP exploratory testing project.

The goal is to verify that the application functions correctly, supports restaurant operations, and provides a reliable user experience.

---

# Test Objectives

The primary objectives are:

- Understand the application's functionality.
- Identify functional defects.
- Verify expected behavior during exploratory testing.
- Document findings for future regression testing.
- Build a reusable set of test scenarios and test cases.

---

# Testing Scope

## In Scope

The following modules will be tested:

- Dashboard
- Front of House
- Inbox
- Content
- Marketing
- Workforce
- System

---

## Out of Scope

The following areas are currently outside the scope of testing:

- Performance testing
- Load testing
- Security testing
- Accessibility testing
- Mobile application testing (if applicable)
- API testing
- Automated testing

These areas may be included in future phases if required.

---

# Testing Types

The following testing techniques will be used:

- Exploratory Testing
- Functional Testing
- UI Testing
- Regression Testing (after bug fixes)

# Test Deliverables

The testing process will produce:

- Application Map
- Risk Assessment
- Exploratory Session Notes
- Test Scenarios
- Test Cases
- Bug Reports
- Regression Checklist
- Test Summary Report

---

# Entry Criteria

Testing can begin when:

- The application is accessible.
- The tester has valid credentials.
- Required environments are available.

---

# Exit Criteria

Testing will be considered complete when:

- All planned modules have been explored.
- High-priority defects have been documented.
- Test documentation has been completed.
- A final test summary has been prepared.

---

# Risks

Potential testing risks include:

- Limited project documentation.
- Unknown business rules.
- Ongoing application changes.
- Incomplete requirements.

---

# Assumptions

The following assumptions apply:

- The application is under active development.
- Exploratory testing is the primary testing approach.
- Business requirements may evolve during testing.
