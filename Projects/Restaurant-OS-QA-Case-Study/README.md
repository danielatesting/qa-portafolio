# 🍽 Restaurant Operating System QA Case Study

> A real-world Software Quality Assurance case study documenting the manual testing of a full-stack Restaurant Operating System.

---

## 📖 Project Overview

This project documents my end-to-end QA process while testing a real Restaurant Operating System used for restaurant management and daily operations.

Rather than focusing only on finding bugs, the goal of this case study is to demonstrate how a QA Engineer approaches an unfamiliar application by understanding business workflows, identifying risks, planning testing activities, documenting findings, and communicating results effectively.

The application includes multiple business domains such as reservation management, floor plans, guest CRM, multilingual content management, newsletters, workforce management, and administrative dashboards.

---

## 🎯 Project Objectives

- Understand the application's business workflows
- Analyze features from a QA perspective
- Identify functional risks
- Perform exploratory testing
- Design test scenarios
- Create professional QA documentation
- Report defects clearly and consistently
- Continuously improve testing based on application knowledge
